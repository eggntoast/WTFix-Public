# Licenses and third-party notices

WTFix-authored material is provided under the repository's [MIT license](../LICENSE), copyright (c) 2026 eggntoast.

Embedded third-party libraries retain their own licensing and attribution; the WTFix MIT license does not replace those terms.

The runtime ships the existing, unmodified `Libs/THIRD_PARTY.txt` and `Libs/LICENSE-Ace3.txt`, plus notices present in the library sources:

- LibStub: public-domain notice.
- CallbackHandler-1.0 and LibDBIcon-1.0: retained Ace3-style BSD notice.
- LibDataBroker-1.1: retained upstream attribution and embedding/distribution note.

Consult those files for the supplied notices. A launcher-only distribution contains no embedded runtime libraries.
